1. Développement Web fullstack

Apprenez à creer des sites et applications web de A à Z.

Objectifs :

  1. Maîtriser la structure d'une page web.
  2. Créer des interfaces modernes et responsives.
  3. Développer la logique côté serveur (Backend).

Compétences acquises :

  1. Frontend :
    • HTML5 & CSS3
    • JavaScript
  2. Backend :
    • Node.js & Express
    • Bases de données (MongoDB)

2. Réseaux Informatiques

Devenez expert dans l'infrastructure et la gestion des réseaux.

Objectifs :

  1. Comprendre le fonctionnement des réseaux locaux (LAN).
  2. Configurer et sécuriser des équipements réseaux.

Compétences acquises :

  1. Certifications Cisco :
    • CCNA
    • CCNP
  2. Configuration :
    • Routeurs & Switches
    • Firewall & VPN

3. Bureautique Avancée

Maîtrisez les outils indispensables en entreprise.

Objectifs :

  1. Rédiger des documents professionnels de qualité.
  2. Analyser des données financières sur tableur.

Compétences acquises :

  • Traitement de texte (Word)
  • Tableur (Excel - Formules avancées)
  • Présentation (PowerPoint)

4. Design Graphique & UI/UX

Créez des expériences visuelles captivantes.

Objectifs :

  1. Maîtriser les logiciels de création graphique.
  2. Concevoir des maquettes ergonomiques pour le web.

Compétences acquises :

  1. Logiciels :
    • Adobe Photoshop
    • Figma
  2. Concepts :
    • UI/UX Design
    • Charte graphique

5. Cybersécurité

Protégez les systèmes d'information contre les menaces.

Objectifs :

  1. Identifier les failles de sécurité.
  2. Mettre en place des stratégies de défense.

Compétences acquises :

  • Tests d'intrusion (Pentesting)
  • Cryptographie
  • Audit de sécurité

6. Data & Intelligence Artificielle

Exploitez la puissance des données et de l'IA.

Objectifs :

  1. Collecter et nettoyer des données massives.
  2. Créer des modèles prédictifs.

Compétences acquises :

  • Langage Python
  • Data Analysis (Pandas, Matplotlib)
  • Machine Learning (Scikit-Learn)
